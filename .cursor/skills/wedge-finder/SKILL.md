# Wedge Finder — FabMakers

## Objetivo

Sair de “ecossistema completo” para **uma ponta afiada** que valida negócio e desbloqueia UX.

## Hard gate

Não editar código. Não redesenhar telas. Só atualizar `docs/brain/` após aprovação do usuário.

## Pré-leitura obrigatória

1. `PROJECT-MEMORY.md`
2. `docs/brain/VISION.md`
3. `docs/brain/ICP.md`
4. `docs/brain/HYPOTHESES.md`
5. `docs/brain/ROADMAP-NOW.md`
6. Skim: `docs/origem_da_ideia.md`, `docs/strategic_plan.md`

## Processo

1. **Diagnosticar cold-start** — Oferta, demanda ou processo? (H1–H3)
2. **Listar 3 wedges candidatos** — cada um com:
   - Persona única
   - Job-to-be-done em 1 frase
   - Caminho feliz (5 passos máx.)
   - O que fica de fora
   - Como medir sucesso em 2–4 semanas
3. **Recomendar 1** — com trade-offs honestos
4. **Perguntar uma coisa por vez** até o usuário escolher
5. **Gravar a decisão:**
   - `DECISIONS.md` → D004
   - `ROADMAP-NOW.md` → wedge escolhido
   - `VISION.md` → norte de curto prazo
   - `ICP.md` → lado pagante prioritário
   - `PROJECT-MEMORY.md` → foco da próxima sessão

## Anti-padrões

- “Vamos fazer um pouco de cada lado”
- Wedge que exige app mobile + designers + API no mesmo sprint
- Escolher wedge só porque já tem mais código (código ≠ validação)
