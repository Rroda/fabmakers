# VISION — FabMakers

> Atualizar quando o posicionamento mudar. Uma frase deve caber no elevador.

## Em uma frase

**A maior rede brasileira de fabricação digital sob demanda** — conecta quem precisa de peça impressa a fabs homologadas com capacidade ociosa, com orquestração (cotação, roteamento, qualidade, pagamento).

## O que É

- Plataforma **asset-light** de manufatura distribuída (modelo “costureira” / Uber da capacidade ociosa)
- Orquestrador neutro: cotação → roteamento → produção → entrega → liberação de pagamento
- Rede de **fabs cadastradas** (qualquer parceiro homologado); marcas D2C externas, se entrarem, são peers iguais

## O que NÃO É (ainda / nunca como núcleo)

- Extensão ou fábrica interna de qualquer loja D2C
- Scraper/revenda de MakerWorld (risco jurídico; designers devem publicar com licença comercial)
- Marketplace completo de designers + manutenção + IA + app + API B2B **no dia 1**

## Norte de longo prazo (visão plena)

Ecossistema multilateral: Cliente · Maker/Fab · Designer · Oficinas de manutenção · (futuro) Empresa/API · Modelagem/IA.

## Norte de curto prazo (wedge)

**Supply-first** — ver `ROADMAP-NOW.md`: fabs homologadas aceitam jobs da fila. Única verdade operacional até validar.

## Métrica de sucesso do conceito

Uma pessoa de fora consegue explicar o produto em **15 segundos** sem listar 5 personas.
