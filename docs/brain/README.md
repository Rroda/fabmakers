# Cérebro de Produto — FabMakers

Memória viva do **negócio e do conceito**. Não é documentação técnica de implementação.

## Ordem de leitura (agente)

1. `../PROJECT-MEMORY.md` (raiz do repo) — estado da sessão
2. `VISION.md` — o que é / o que não é
3. `ICP.md` — para quem
4. `CONCEPT-MAP.md` — peças conectadas vs soltas
5. `HYPOTHESES.md` — apostas abertas
6. `DECISIONS.md` — o que já foi decidido (não reabrir sem motivo)
7. `ROADMAP-NOW.md` — o wedge atual

## Skills deste cérebro

Em `.cursor/skills/`:

| Skill | Quando usar |
|-------|-------------|
| `wedge-finder` | Produto amplo demais / estagnado / precisa de 1 foco |
| `concept-reconnect` | Features desconectadas da narrativa |
| `product-council` | Decisão estratégica com múltiplos ângulos |
| `product-ui` | UI/UX só depois do conceito estar claro |

## Regra de ouro

- Sessão de **estratégia** → só `docs/brain/` (+ perguntas). Sem código.
- Sessão de **UI** → skill `product-ui` + `VISION` + `ROADMAP-NOW` + regra `.cursor/rules/fabmakers-ui.mdc` (base [mistral.ai](https://mistral.ai/)).
- Sessão de **código** → plano aprovado; Superpowers/brainstorming se for feature nova.

Fontes históricas (não substituem o brain): `origem_da_ideia.md`, `strategic_plan.md`.
